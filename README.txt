COMPUTER REPAIR APPOINTMENT AND SERVICE MANAGEMENT SYSTEM
Java Swing UI Prototype

HOW TO RUN IN VS CODE
1. Open this folder in VS Code.
2. Make sure JDK 17 or newer is installed.
3. Open the src folder.
4. Run Main.java.

LOGIN
The prototype accepts any username/password because this version is UI-only.
The login will open the dashboard.

IMPORTANT
This is a prototype. It currently uses sample data and does NOT connect to Supabase.
The next development step is:
Java Swing UI -> PostgreSQL JDBC -> Supabase PostgreSQL

MAIN MODULES
- Dashboard
- Customers
- Computers
- Appointments
- Repair Requests
- Technicians
- Repair Services
- Payments

REPAIR STATUS
- Pending
- Confirmed
- Under Diagnosis
- Under Repair
- Waiting for Parts
- Ready for Pickup
- Completed

The UI is intentionally kept simple so it can be expanded during database integration.
